Foundational Concepts & Comparisons

  1. Supervised vs. Unsupervised Learning: Beyond the basic definitions provided in the slides, how would you determine whether a given business problem is better suited for supervised versus unsupervised learning? Provide a real-world scenario where the boundary between these approaches might be blurred.

  2. Regression vs. Classification: The slides state regression predicts "infinitely many possible outputs" while classification predicts "a small number of possible outputs." Could you design a problem where a regression model and a classification model could both be applied, and explain the trade-offs of each approach? When might you choose regression over classification even for a categorical outcome?

  3. Arthur Samuel's Definition: Samuel defined machine learning as giving computers the ability to learn without being explicitly programmed. The slides show a checkers program that improved through self-play. How does this definition relate to the modern supervised learning paradigm? What aspects of modern ML would Samuel's definition not fully capture?

Gradient Descent Mastery

  1. Learning Rate Selection: The slides warn about learning rates being "too small" or "too large." Design a systematic approach for selecting an appropriate learning rate for a new dataset. Include how you would detect that your learning rate is suboptimal during training and what metrics you would monitor.

  2. Local Minima in Linear Regression: The slides show a cost function with "more than one local minimum." However, for linear regression with squared error, the cost function is convex. Explain this apparent contradiction. Under what conditions could linear regression with squared error have multiple local minima?

  3. Simultaneous Update: The gradient descent algorithm requires simultaneous updates of w and b. What would happen if you updated w first, then used the updated w to compute b? Derive the mathematical consequences and explain why the simultaneous update is crucial.

  4. Derivative Intuition: The slides explain that near a local minimum, derivatives become smaller, so update steps become smaller. Mathematically prove that for the squared error cost function, the gradient norm decreases as you approach the minimum. What assumptions are needed for this proof?

  5. Batch Gradient Descent Definition: The slides define "Batch" gradient descent as using all training examples in each step. Compare and contrast this with stochastic gradient descent and mini-batch gradient descent. For a dataset with 10 million examples and limited computational resources, which approach would you recommend and why?

Advanced Theoretical Questions

  1. Feature Scaling: Though not explicitly covered in these slides, suppose we have two features: house size (ranging 500-5000 sq ft) and number of bedrooms (ranging 1-5). How would the contour plot of the cost function look before and after feature scaling? Explain how this affects gradient descent convergence using the concepts from the slides.

  2. Normal Equations vs. Gradient Descent: For linear regression, the optimal parameters can be found analytically using the normal equations. When would you prefer gradient descent over the closed-form solution? Consider factors like computational complexity, dataset size, and numerical stability.

  3. Generalization to Multiple Features: The slides focus on univariate linear regression. Extend the concepts of the model, cost function, and gradient descent to multiple features. How would the gradient descent update rules change, and what new challenges arise?

  4. Early Stopping: The slides show gradient descent converging over iterations. How would you determine when to stop the algorithm? What are the trade-offs between stopping early versus running until convergence, especially in the context of preventing overfitting?

Application & Scenario-Based

  1. Spam Filtering Example: The slides show spam filtering as a supervised learning application. Design a complete ML pipeline for spam detection, including how you would handle the challenge of evolving spam patterns over time. How would you incorporate the concepts from unsupervised learning to improve your system?

  2. Housing Price Prediction with Limited Data: You're tasked with predicting housing prices but only have 10 training examples. How would your approach differ from having 10,000 examples? Discuss the impact on model selection, parameter estimation, and the reliability of your predictions.

  3. Anomaly Detection Integration: The slides mention anomaly detection as an unsupervised learning application. How would you combine supervised learning (for main predictions) with unsupervised learning (for anomaly detection) in a production system? Provide a concrete example from the housing price prediction scenario.

  4. Recommender Systems Context: While recommender systems are mentioned, the slides focus on linear regression. How would you adapt the concepts of linear regression to build a simple recommender system? What would be the input features, the target variable, and how would you handle the cold-start problem?

Conceptual Synthesis

  1. Machine Learning Taxonomy: The slides present supervised learning, unsupervised learning, recommender systems, and reinforcement learning. Create a unified framework that shows how these approaches relate to each other. When would you use a combination of these approaches in a single application?

  2. Interpretability vs. Accuracy: For a medical diagnosis application (like the breast cancer detection mentioned), would you choose a linear regression/classification model or a more complex model? Justify your answer using concepts from the slides about model parameters, cost functions, and the trade-offs in ML.

  3. Data Quality Impact: The slides show that more training data (tens of thousands of games for the checkers program) improves performance. Discuss the relationship between data quality, data quantity, and model complexity. When would adding more data NOT improve model performance?

  4. Evaluation Metrics: The slides focus on squared error as a cost function. For classification problems (like spam detection), what alternative evaluation metrics would you use? How would you incorporate these into the training process, and what are the trade-offs?

  5. Production Deployment: You've trained a linear regression model for housing price prediction that performs well on your validation set. Walk through the steps you would take to deploy this model in production, including monitoring, retraining, and handling data drift. Use concepts from the slides about the learning algorithm, parameters, and model updates.
